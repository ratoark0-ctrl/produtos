# Gerenciador de Produtos [Terminal]
Projeto realizado em grupos na sala de aula.
## Objetivo
Compreender como funciona o trabalho em grupo em uma equipe de desenvolvidores, analistas e testrs.
## Componentes
### Lógica de Programação 
Estamos desenvolvimentos em grupos algoritmo utilizando python 3.1x.
### Redes
Fazemos o "deploy" do código em uma máquina virtual - Ubumtu Server.
### Processo de Desenvolvimento de software
Registramos requisitos funcionais e não funcionais, realizamos testes e aprendemos sobre o básico de CI/CD
